# BCA Semester 3 Portfolio

**Author:** Aman Kumar

A collection of beginner-friendly programming practice and mini-projects created during BCA Semester 3.

## Contents

- `Java/` — Java practice programs
- `CPP/` — C++ practice programs
- `Web-Development/` — HTML, CSS and JavaScript mini-project

## How to use

1. Download or clone this repository.
2. Open a language folder in VS Code or your preferred editor.
3. Read the comments at the top of each source file.
4. Run the programs using the compiler or runtime for that language.
